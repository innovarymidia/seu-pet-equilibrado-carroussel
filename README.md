# Seu Pet Equilibrado - Gerador de Carrosséis com IA 🐕✨

Sistema inteligente de múltiplos agentes de Inteligência Artificial para geração autônoma de **carrosséis de alta conversão, autoridade e engajamento no Instagram**, focado exclusivamente no nicho de **Adestramento e Comportamento Canino Equilibrado**.

---

## 🎯 Filosofia de Conteúdo: Adestramento Equilibrado
O sistema foi calibrado para refletir a metodologia de **adestramento equilibrado**:
- **Comunicação Clara e Bidirecional:** O cão aprende o que é recompensado e o que não é permitido.
- **Sem Ilusões do "100% Positivo":** Que falha em situações reais de alta distração, perigo ou reatividade grave.
- **Sem Punitivismo / Crueldade:** Repúdio a agressões ou métodos que destroem a confiança e o vínculo entre tutor e cão.
- **Foco em Liderança Calma & Estrutura:** Rotina previsível, limites gentis e consistentes, passeio estruturado e autonomia emocional.

---

## 🤖 Time de Agentes Autônomos
1. **Max Thorne (Estrategista Chefe):** Mapeia as dores profundas dos tutores (guia puxando, reatividade, ansiedade de separação, destruição) e define o gancho psicológico.
2. **Helena Vance (Copywriter Canina):** Escreve títulos hipnóticos e slides objetivos, sem clichês, com storytelling envolvente e CTAs de alta conversão.
3. **Designer Visual:** Define a hierarquia tipográfica, contraste, paleta esmeralda/dourado e respiração dos elementos.
4. **Agente de QA:** Revisa a clareza, sanitiza quebras de linha e garante o tom equilibrado e profissional.
5. **Publisher:** Monta a legenda completa para o Instagram com ganchos e hashtags segmentadas.

## 🚀 Como Executar Localmente
```bash
# 1. Instalar dependências
npm install

# 2. Configurar variáveis de ambiente (.env.local)
GEMINI_API_KEY=sua_chave_do_gemini

# 3. Rodar servidor de desenvolvimento
npm run dev
```

Acesse em [http://localhost:3000](http://localhost:3000).
